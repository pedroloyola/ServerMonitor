A redesigned interface and new features since ServerAlyzer 1.1.

A new look. A sidebar takes you to Overview, Servers, History and Settings, each server has its own detail page, and compact mode and the Windows 11 widget were redesigned. Keyboard use, screen readers and high contrast were reviewed across the app.

Easier setup. A first-run guide helps you add your first server. You can import hosts from your SSH config file, the app suggests private keys it finds in your .ssh folder, and the connection test shows each step so you can see what failed.

Jump hosts. Servers reached through one ProxyJump host are now supported, and the jump host's key is checked separately.

Encrypted backup. In Settings you can save your servers, trusted host keys and saved passwords to a file protected by a passphrase you choose, and restore it on this or another computer. Private key files are never included.

Language. If Windows is not set to Portuguese, the app now opens in English. A language you already chose in Settings is kept. If the app opens in Brazilian Portuguese and you prefer another language, change it in Settings > Language.

The local network search only runs when you ask. With no servers added yet, choose "Search local network"; Windows may ask for network permission.

The .NET runtime is now included, so the app works on PCs without .NET installed.
