ServerAlyzer 1.1.8 improves screen reader support and alert reliability.

Screen readers. On the Servers page, a server whose data is out of date now tells screen readers how old that data is. When a local network search ends on its own, screen readers now announce how it ended.

Alerts. If you removed a server while one of its notifications was showing and then added it back, its next alert could be held back for up to 5 minutes. That no longer happens.

Portuguese. In the server editor, the example text in the fields now says "Por exemplo:" instead of "Ex.:", which screen readers read more clearly.
