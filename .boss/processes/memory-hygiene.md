# Process — Memory hygiene

> O Boss é responsável pela manutenção da memória. Evitar acumulação infinita de notas duplicadas.
> Comandos do utilizador: "Boss, limpa a memória" · "consolida os aprendizados do Mx" · "mostra os pitfalls".

## Rotina (periódica ou a pedido)
1. **Consolidar** — juntar entradas relacionadas; promover pitfalls recorrentes a learnings.
2. **Resumir** — encurtar entradas verbosas mantendo o essencial.
3. **Arquivar** — mover histórico obsoleto mas valioso para `.boss/reports/archive/`.
4. **Eliminar duplicados** — mas **nunca** apagar notes do Maestri sem pedido explícito do utilizador (regra do CLI).
5. **Atualizar obsoletos** — datas relativas → absolutas; verificar que ficheiros/funções citados ainda existem.
6. **Detetar contradições** — entre HANDBOOK/PITFALLS/LEARNINGS/código; sinalizar ao utilizador.

## Higiene ao escrever
- Uma ideia por entrada; ligar com IDs (`[P-00x]`, `[L-00x]`).
- Só registar o que melhora trabalho futuro. Sem trivia, sem chain-of-thought.
- Segurança: nunca guardar segredos (§9 do BOSS.md).

## Sincronizar camadas
- Após consolidar `.boss/`, refletir o essencial nas notes/fichários do Maestri (Boss Workspace) e no `MEMORY.md` do Claude Code (só o ponteiro).
